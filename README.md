## 🚀 Featured Project

### ⚡ SysPulse

A lightweight Linux system utility written in **C**, focused on displaying system information and monitoring useful hardware metrics.

Current idea:

```text
SysPulse
├── System information
├── CPU information
├── Memory usage
├── Temperature monitoring
└── Fast terminal output
```

The goal is to keep it **fast, lightweight and Linux-focused** while improving my knowledge of low-level programming and the Linux environment.
